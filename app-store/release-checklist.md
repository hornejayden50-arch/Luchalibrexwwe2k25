# App Store Release Checklist

## Google Play
- [ ] Create app in Google Play Console.
- [ ] Upload signed Android App Bundle (`.aab`).
- [ ] Complete Data Safety form.
- [ ] Add privacy policy URL.
- [ ] Fill in store listing text/screenshots/icon.
- [ ] Submit production release.

## Apple App Store
- [ ] Create app in App Store Connect.
- [ ] Set bundle identifier to `com.luchalibre.triosshowcase`.
- [ ] Archive signed iOS build in Xcode.
- [ ] Upload build via Organizer.
- [ ] Fill App Privacy and age rating.
- [ ] Provide screenshots and metadata.
- [ ] Submit for review.
